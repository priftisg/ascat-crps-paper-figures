\caption{
Global distribution and characteristics of cold-pool objects in the
multi-mission ASCAT catalog. (a)~Overpass-normalized object detection
frequency on a $0.5^{\circ}$ grid, calculated as the number of cold-pool
object centroids divided by the combined ASCAT-A, -B, and -C overpass
count and expressed as a percentage. (b)~Mean area of detected cold-pool
objects within each grid cell. Cells with fewer than 20 overpasses are
masked in (a) and (b). (c)~Seasonal contrast in overpass-normalized
detection frequency, defined as $f_{\mathrm{DJF}}-f_{\mathrm{JJA}}$; cells
with fewer than five estimated seasonal overpasses
[$N_{\mathrm{overpass}}\times(3/12)<5$] are masked. All panels are derived
from the density-matched object catalog using
$\tau=1.2\times10^{-4}$~s$^{-1}$ and $p^{*}=0.325$.
}
\label{fig:global_distribution}
